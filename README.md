## Academic and Research Projects

### Microrobots Methodology
Development of an automated Python pipeline for the statistical analysis and visualization of microrobot behavior under different experimental conditions.
- **My role**: Development of the complete software architecture, implementation of statistical validation logic (Bootstrap, Mann-Whitney), and creation of a bilingual automated reporting system.
- **Code repository**: https://github.com/juanfehs/microrobots-metodologia

### SAE - Sistema de amortiguación electromagnético (Electromagnetic Amortiguation System)
Collaborative project developed as part of an academic course.
- **My role**: PCB design and validation, experimental design, evaluation metrics, and interpretation of results.
- **Code repository**: https://github.com/martin10ca/sae

### Code a Chip A51LCipher
Collaborative project developed as part of an IEEE SSCS competition of chip design.
- **My role**: Digital design, theoretical encryption analysis, and programming.
- **Code repository**: https://github.com/martin10ca/Code_A_Chip_A51LCipher
